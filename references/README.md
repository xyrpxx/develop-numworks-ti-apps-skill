# Références techniques

Les détails sont organisés par sujet. Commence par le [guide principal](../SKILL.md), puis consulte la référence pertinente :

- `scope-and-targets.md` : choisir la cible et qualifier les preuves.
- `numworks-eadk.md` : chaîne EADK, API et format NWA.
- `ti-ce-toolchain.md` : CEdev, GraphX, ABI et lancement TI CE.
- `portable-architecture.md` : noyau C partagé entre plateformes.
- `display-input-performance.md` : rendu, clavier et performances.
- `storage-numworks.md` et `storage-ti-ce.md` : méthodes de persistance propres à chaque plateforme.
- `save-format-and-recovery.md` : format, validation et récupération.
- `testing-and-debugging.md` : essais et diagnostic.
- `release-and-troubleshooting.md` : livraison et problèmes courants.
