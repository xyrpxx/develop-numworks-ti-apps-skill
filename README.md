# Développer des apps C NumWorks et TI CE

Ce dépôt contient le skill `develop-numworks-ti-apps` pour orienter les agents qui créent, portent, testent et livrent des applications C pour NumWorks EADK et TI CE avec CEdev.

Commence par lire [SKILL.md](SKILL.md). Les références détaillent les chaînes d’outils, l’architecture portable, les sauvegardes NumWorks et TI, ainsi que les tests et le dépannage.
